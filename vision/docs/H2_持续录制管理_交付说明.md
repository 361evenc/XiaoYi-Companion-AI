## 二、三个关键设计（也是这张卡真正难的地方）

### 1. "说停就真停" —— 不是状态字段，是硬件事实

F-2 的原话是"**说停了实际还在录**是信任头号杀手"。所以本卡把"停"拆成三层，每层都能验：

| 层 | 做了什么 | 怎么验证 |
|---|---|---|
| 代码层 | `stop()` → 线程退出 → `src.release()` → 删除帧源引用 | 看 `recorder.py` 的 `finally` 块 |
| 硬件层 | `verify()` 重新打开摄像头 | 打得开 = 真释放；打不开 = 报故障，不报"已停" |
| 对外层 | `status().confirmed_off` 只有 `released` 才为 `True` | 前端不许自己拼判断逻辑 |

**关键区分：故障 ≠ 已停。** 两者话术和风险完全不同：

```
released  → "我现在不看啦"（真停，可以放心说）
fault     → "我没法确定摄像头停了，请重启一下电脑"（故障，绝不能说他停了）
recording → 还在录
```

### 2. 首帧自检 —— "能打开"不等于"能出帧"

实测发现：USB 松动 / 驱动异常时，`cv2.VideoCapture` 经常**能打开但读不到帧**。
如果这时报 `recording`，就是另一种形式的"假装在录"。

所以启动流程是：开摄像头 → **真读一帧** → 读到了才报 `recording`，读不到直接 `fault`。

### 3. 原始帧零落盘 —— 代码可验证，不靠承诺

```python
rec = describe_frame(frame, meta, model)   # 帧只在这一行里存在
append_jsonl(FRAMES_FILE, rec)             # 只写结构化条目
del frame                                  # 主动断引用，不等 GC
```

验收脚本用**静态扫描**保证这条路线没被以后的人改坏：
录制链路上出现 `cv2.imwrite` / `VideoWriter` / `.tofile(` / `Image.save(` /
`requests.post` / `urlopen` 任何一条 → `[FAIL]`。

## 五、已知限制（诚实列出）

1. **Windows 上"设备被占用"构造不出来**：实测本机摄像头驱动允许多进程同时打开，
   没有互斥。所以验收用例改走"读不到帧 / 设备不存在"这条真路径。
   Linux 或部分 USB 摄像头驱动有互斥，届时"被占用"会表现为 `fault`，逻辑已覆盖。
2. **`verify()` 会短暂占用摄像头**，不能高频调。目前只在 `stop()` 后调一次。
   如果以后要在指示灯上"实时确认"，需要改成低频轮询（如 60s）。
3. **音频（听）开关只是占位**：`audio_enabled` 恒 `False`，MVP 不采集音频。
   F-2 要求"别看了"和"别听我的"两个独立开关，视觉这半边已就位，音频那半边
   要等真正接入音频采集的卡。
4. **后端接口未做端到端联调**：本机视觉 venv 没装 fastapi，后端主环境也没装。
   `vision.py` 与 `main.py` 只做了语法校验。真联调要等小忆后端环境起来。
5. **模型首次加载慢**：`describe_frame` 首次 import 要拉 torch/ultralytics，
   实测几秒到十几秒。启动接口最多等 20s 才返回，期间状态是 `closing`。
   前端 F-2 在 `closing` 时不要显示"小忆在看"。

## 七、接口清单（给 F-2 / 其他人）

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/vision/status` | 状态快照（指示灯） |
| POST | `/api/vision/start?source=camera&interval=2` | 开 |
| POST | `/api/vision/stop` | 关（内含 verify，响应带 `verified`） |
| GET | `/api/vision/verify` | 主动验证 |

`status` 返回字段（前端只读这些，不要自己拼）：

```json
{
  "state": "recording|released|fault|closing|idle",
  "detail": "人话说明",
  "vision_on": true,
  "audio_on": false,
  "confirmed_off": false,
  "frames": 12345,
  "errors": 0,
  "last_frame_ts": "2026-11-07T12:30:00",
  "started_at": "...", "stopped_at": null,
  "interval": 2.0, "source": "camera"
}
```

**话术映射**（F-2 直接用）：

| `state` | 显示文字 | 颜色（辅） |
|---|---|---|
| `recording` | 小忆在看 | 蓝 |
| `released` | 没在看 | 黄 |
| `fault` | 我没法确定 | 红（配"请重启一下电脑"） |
| `closing` | 正在… | 灰 |
