## 四、隐私边界是怎么做到的（这段是答辩要讲的）

任务卡的红线是"通话帧零落盘"。这条如果只靠"我没写保存代码"来保证，是不可验证的承诺。
所以做成两层：

**第一层：实现上不给路**
- 摄像头流 `getUserMedia({video:true, audio:false})` 只赋给 `<video>.srcObject`，浏览器自己渲染
- 页面里**没有任何** `canvas`、`toDataURL`、`toBlob`、`drawImage`、`captureStream`
- 页面里**没有** `fetch`、`FormData`、`/api/photo` —— 唯一出网的是 `asr`（音频）和 `chat`（文字）
- 音频是**单独一路**录音器（16k 单声道 WAV），与画面无关

**第二层：脚本可复验**
`frontend/tests/h1_privacy_check.mjs` 扫描源码，禁止项出现即失败、必须项缺失即失败。
队友或评委可以随时重跑，不依赖我的口头说明。

```bash
node frontend/tests/h1_privacy_check.mjs
# 退出码 0 = 通过
```

## 五、已知限制（P0 就这些，P1 补）

1. **通话帧不做任何识别** —— 这是任务卡规定的（识别拆到 H-12：在不在/看没看/表情/手持物品）。
   P0 只保证"能看见、能说话"。
2. **说话是"点一下开始、点一下结束"**，不是全双工自动打断。
   全双工要 VAD + 回声消除，属 P1 体验优化。当前形态对老人反而更明确（有明确的"我该说了"信号）。
3. **摄像头打不开不阻塞通话** —— 会降级成语音通话并如实说明原因（没授权/被占用/没设备），
   老人照样能聊。不硬装"看得见"。
4. **形象是内联 SVG 简笔形象**，不是数字人。任务卡允许"MVP 用 2D 形象图+口型/点头动画"。
   单独的形象资源图暂无，先用 SVG 保证零外部依赖、可离线。
5. **TTS 依赖后端火山 key** —— 没 key 时后端返回 `audio_url=null`，此时只有字幕没有声音，
   页面不报错（`playReply` 里 url 为空直接返回）。
