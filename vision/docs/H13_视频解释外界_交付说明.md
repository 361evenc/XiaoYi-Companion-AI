## 二、三条边界的实现方式

### 2.1 安全抢占：不产生，而不只是"不播"

```python
def explain(self, frame, what):
    if self._safety_busy():              # 第一道：算之前查
        return self._suppress(what)      # 返回 text=""，且已写事件日志
    ... 计算 ...
    if self._safety_busy():              # 第二道：算完再查（算的过程中可能触发告警）
        return self._suppress(what, why="fall_alarm_triggered_mid")
```

关键选择：抢占时返回 `text: ""`，**不是"生成了但标记为不播"**。少一层状态，就少一层"以为没播其实播了"的可能性。第二道检查是因为一次解释要跑 CLIP + YOLO，可能几百毫秒——这期间老人摔了，照样要拦。

`fall_guard` 导入失败时按"占用"处理（保守失败）：解释功能坏掉无所谓，安全告警期间误播一句"外面是晴天"才是事故。

接口层只暴露 `/api/explain/tick`，**没有 force 参数**——绕过安全优先在物理上做不到。

### 2.2 门口：代码层面的"不记是谁"

```python
for i in range(len(r.boxes)):
    if r.names[int(r.boxes.cls[i])] == "person":
        best = max(best, float(r.boxes.conf[i]))
del r                     # ★ 框在这里就丢了，函数外拿不到任何位置/人脸信息
```

结果里只有 `{"person": bool, "conf": float, "privacy": "person_presence_only"}`。自测逐项断言结果字典里不含 `face/gender/age/identity/name/bbox` 六个键。去抖 3 秒——有人在门口站一会，不该念三遍。

### 2.3 电视：必须先确认"真有电视"

**这是本次唯一一个测出来的真 bug，值得单说。**

第一版只做 CLIP 分类。测 `frames/18_living_bright.jpg`（明亮客厅、**根本没开电视**）时，输出：

```
电视上看着像在播综艺节目。   conf = 0.785
```

CLIP 是**相对打分**的：给它 9 个节目类型，它一定选一个"最像的"，哪怕画面里压根没有电视。这跟 `clip_zeroshot.py` 早就踩过的坑是同一个（室内图被判"下雪 0.51"）。

修法：加前置检查——先问 YOLO 画面里有没有 `tv`/`monitor` 框，没有就**不开口**（不是"没看明白"，是根本没这东西）。有电视再做 CLIP。

> 顺带发现：这张图里扣着合盖的笔记本被 YOLO 判成 `laptop`（0.444）。我起初把 `laptop` 也算"屏幕"，但合盖的笔记本屏幕上什么都没有——说"在播综艺"同样是编。所以只认 `tv`/`monitor`，且概率 ≥0.40。代价是手机/平板播节目不被识别，**宁可少说一项，不能对着没开的电视瞎说**。

### 电视链路的状态说明（诚实）

图集里**没有一张真实的"电视正在播节目"的照片**，所以 [6]（不复述内容的句式检查）被跳过。电视分类的 CLIP 打分链路能跑通（在没有电视的图上也能给出分数，说明模型和提示词是通的），但"有电视时判得准不准"**没有数字**。要补这个数字，需要用户拍 10-20 张电视正在播的图。

这不影响 [5] 那条回归——它是"不许瞎说"的检验，已经用真实图片测过了。

## 四、接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/explain/config` | 阈值 + 优先级 + 三条隐私边界说明 |

## 七、交给下游

- **→ 对话层**：`text` 是可直接播的一句话；为空字符串代表"这一拍没什么要说的"，**不要拿空串去追问**（追问会让老人觉得设备坏了）。
- **→ 前端（F 线）**：`status().safety_busy == true` 时，界面上任何"让小忆看看外面"的按钮都应置灰——不是前端拦，是后端根本没内容返回，置灰只是别让老人白点。
- **→ P2 批次试用**：`explain_events.jsonl` 里 `event=explain` 的记录含 `text` 和 `items`，可直接统计"一天解释了几次、几次是'没看明白'"。
