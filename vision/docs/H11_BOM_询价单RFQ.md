## 二、报价标的（四选三发，按 H-8 拍板方向定；拿不准就四家都发）

### 形态 A：10.1" 平板一体机（基准形态，有现成方案，报价最快）

| 项 | 规格（与 H-9 选型表一致） |

### 形态 B：数码相框形态
同 A 的主板/麦/摄像头/灯，但外形为 10.1" 相框（横置、木纹或布纹外壳、无触摸、
摄像头藏在边框顶部并在物理开关断电时**指示灯同步熄灭**）。

### 形态 C：音箱形态
同 A 的主板/麦/灯，屏缩到 4"（或无屏、纯语音+指示灯），喇叭升级 5W，
圆柱形织布外壳，摄像头位于顶部并带物理遮挡滑盖（不是电子开关）。

### 形态 D：电视拨号盒形态
同 A 主板/麦/灯，**无屏**，HDMI 输出接用户已有电视，遥控器或语音拨号，
机顶盒式卧式外壳。摄像头为外接 USB 摄像头（3m 线），带物理遮蔽盖。

## 三、要求供应商按这个格式报（不按格式的报价没法比）

| 明细项 | 要求 |
|--------|------|
| NRE / 模具费 | 一次性，分开报（外壳模具、支架模具、治具） |
| 单台价 | 分三档报：**50 台 / 500 台 / 1000 台**（含税含装配，含包装） |
| 打样 | 首版 5 台：单价、周期（工作日）、含几次结构修改 |
| 量产爬坡 | 首批 50 台交付周期 |

| 质保 | 保修期、不良率承诺（返修率 ≤2% 起） |
| 供货 | 主控/屏的备货周期与停产风险（RK3566 与 10.1" IPS 目前供价波动要说明） |

## 四、目标价锚点（拿这个压价，不是拿这个被锚）

- H-8 粗估：形态 A 500-700 元 / B 400-600 / C 450-650 / D 350-500（1000 台量）
- 外部参照：公版 10.1" RK3566 安卓平板整机 FOB **$50-65/台**（1000 台量），
  这是我们 B 表的上限逻辑——形态 A 的报价**显著高于这个数+增值件（麦阵列+结构）
  的合理成本**时，直接问对方贵在哪
- ElliQ 硬件 $249.99 的教训：硬件定价不是越低越好，是**不亏或少亏**——
  所以砍价目标不是无限低，是 BOM ≤600 元内留出服务费空间

## 五、询价时要一并问清的三个问题（写在邮件里，答案影响 H-8/H-9）

1. **4 麦环形阵列你们是自研还是采购现成模组？** 现成模组型号、单价、是否带回声消除
   （AEC）——这直接决定语音链路里 ASR 前端的成本与效果（H-9 语音预算待补项）
2. **摄像头物理断电开关你们做过吗？** 要的是"断电后软件完全无法打开摄像头"的
   硬件开关，不是 App 里的开关。做过的话给案例（这是隐私红线，没做过的供应商
   需要加 NRE，要提前知道）
3. **3C 新规**（2025-05 起移动电源类"型式试验+工厂检查+获证后监督"）对带电池
   配置的形态 B/C 影响多大？——若走纯插电形态 A，3C 按整机 ITE 类走，费用约
   2-4 万/2-3 个月；带电池要加什么，请对方列
