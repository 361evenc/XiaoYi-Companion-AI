## 三、两次翻车与教训（比数字更值钱）

**翻车 1：YOLO 用"屏幕里有没有人"判断电视。**
黑屏 tv=0.92、纯白 0.92、新闻主播 0.81——但真播动画时 0.00-0.48，**真在播节目反而认不出**。

**翻车 2：用 CLIP 分数给 YOLO 兜底 → 引发回归。**
CLIP 给空客厅打 0.987 相似度，no_tv 反例组 7/16 误开口。已回退，保留 YOLO conf≥0.40 作唯一判据，接受漏报不冒险误报。

**两条教训（已写进代码注释与交付文档）：**
1. 阈值必须用**真正会走进该分支的样本**对撞；拿被上游过滤掉的样本估阈值 = 拿空集定阈值。
2. CLIP 是相似度不是检测器，永远不能做"存在性"判断。
3. （附）"用错样本算出的指标比没有指标更坏"——英文古董药盒测中文说明书那次，指标是假的。

## 四、H-8 硬件形态 · 已拍 C 音箱 + 屏方案三选项（重点，供商量）

### 已拍板：C 圆柱音箱形态（发起人本人，11-07）

- 外观：圆柱织布外壳（φ10cm × 18cm），顶盖集成摄像头 + **物理滑盖** + 工作指示灯
- 麦克风：4 麦阵列；喇叭 5W（78dB@1m，织布吸声损耗预留）
- 摄像头物理断电：软件必须能识别滑盖状态（隐私红线）
- 张力已如实记录：视觉 AI 不受影响 ✅；**视频通话被削弱**——这正是下面三选项要解决的

### 屏方案三选项（每个选项的应用蓝图）

#### 选项 1：带 4 寸屏版（BOM +60~90 元）

**硬件**：顶面下倾 4 寸触屏，其余同 C。

**应用蓝图**：
- 老人早上醒来，屏幕亮起"今日提醒"看板：9 点降压药、女儿 14:00 来视频。
- 来电时屏幕显示对方头像大图 + "接听 / 拒接"两个大按钮，按下即通。
- 通话中对方出现在 4 寸屏上，老人可以举着音箱在屋里走动（类似老式无绳电话）。
- 摄像头滑盖关着时，屏幕显示"摄像头已关闭，对方看不到你"——隐私状态一目了然。
- 不通话时，屏幕轮流显示天气、日期、家人留言卡片（家属在小程序端发一张照片+一句话，屏幕当天展示）。

**代价**：BOM 上浮 60-90 元；圆柱顶面开屏增加结构/模具复杂度；开发量 +2~3 周。

#### 选项 2：纯语音版（无屏，BOM 最低）

**硬件**：C 标准形态，屏 0 元。

**应用蓝图**：
- 老人说"小忆，给女儿打电话"，音箱语音确认"要接通吗？"→ 呼出。
- 接听后**通话发生在女儿的手机上**，老人这边是免提音箱——老人不用学任何屏幕操作。
- 音箱平时就是个"会看的音箱"：药盒放它面前能报药名，电视开着能讲节目，跌倒能告警。
- 来电提醒靠语音+灯光闪烁（织布外壳透光弱，需顶盖开灯窗，模具上预留）。

**代价**：视频通话体验降级为"语音通话 + 对方单方面看"；漏掉"老人也想看到人"的情感场景（老人看子女/孙辈，这是核心情感需求，砍掉最伤）。

#### 选项 3：电视联动版（HDMI 借用老人已有电视，BOM +30~50 元）

**硬件**：机身侧面 HDMI-out，其余同 C。

**应用蓝图**：
- 平时就是普通音箱，电视用老人的有线电视/机顶盒。
- 来电时电视自动切到 HDMI 源，全屏显示"女儿来电"——**老人最熟悉的设备承担了显示**，字大、看得清。
- 通话画面出现在自家电视上，老人坐在沙发上面对面聊，体验最接近"见面"。
- 家属小程序端可发"电视相册"，空闲时段电视上轮播孙辈照片。

**代价**：依赖老人家里电视 + 电视就在身边的使用场景；客厅外（卧室、厨房）通话回落为纯语音；HDMI 线布线要考虑；开发量居中。

### 三选项对比

| | 通话体验 | BOM | 依赖设备 | 开发量 |
|---|---|---|---|---|
| ① 4寸屏版 | ★★★ 双向可视 | +60~90 | 无 | 最多 |
| ② 纯语音版 | ★ 仅语音 | 基线 | 无 | 最少 |
| ③ 电视联动版 | ★★★（客厅内） | +30~50 | 电视 + 位置 | 居中 |

**决策规则建议**：如果发起人判断"老人看子女"是核心情感需求 → ①或③；如果首发要控成本、快速验证 → ②，通话让给手机，等 BOM 降了再加屏。
