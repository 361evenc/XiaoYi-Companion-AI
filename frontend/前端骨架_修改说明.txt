前端骨架 · 修改说明
生成时间：2026-10-28

一、修改原因
按《前端重构_任务清单.md》Phase 2，把「小忆」App 的前端从 Gradio 换成 Vue3 + Vite。
本阶段只做「静态骨架 + 设计系统」，不接后端接口（接口留 Phase 3+）。
采用并存策略：新建 frontend/，不动 app.py 与 backend/。

二、采用方案
- 框架：Vue 3 + Vite + Vue Router + Pinia + axios
- 无登录无 token：会话状态（姓氏/性别/性格/静音）由 Pinia 存 localStorage，请求体传后端
- 接口：axios 已按后端端点预留封装（api/index.js），Phase 2 仅占位不调用
- 布局：欢迎页 → 主界面（左栏 4 卡片 + 右侧聊天）→ 3 个二级页（记忆箱/历史/隐私），带←返回
- 响应式：桌面（左栏 340px）/ 平板（280px）/ 手机（左栏折叠为顶部横排）三端自适应

三、设计系统落地（老人友好红线，全部照做）
- 暖米底 #FEF8ED；只留 2 强调色：焦糖 #C88A52 + 深青绿 #3E825F
- 正文 18px、聊天气泡 20px、按钮高 ≥48px、圆角 8/12/16、正文深棕 #2D1B0E 对比度达标
- 主按钮焦糖底+深字、危险操作深红 #B3402F、成功/强调用深青绿，均确保文字对比 ≥4.5:1

frontend/

六、端口说明（重要）
- 本机 5173 已被无关项目「光影重生」占用的 dev server 占用
- 因此本项目的 `npm run dev` 会自动切到 5174（Vite 默认行为）
- 启动方式（在 frontend/ 目录下）：
  cd frontend
  npm install
  npm run dev
  然后浏览器打开 http://localhost:5174
