输入区优化：仿微信聊天输入框（反馈3 / P2 局部收口）
修改文件：app.py
修改日期：2026-10-27

【修改原因】
客户觉得原输入区偏简陋/杂乱，希望"只优化输入框部分，仿照微信聊天框简单大气，
整体保持暖色调、适合老人"。因此不改全面布局，只重塑底部输入区。

【修改内容】
1. 结构：把原「输入区一行（输入框+发送+静音）+ 下方工具栏一行（🎙️🖼️📷）」，
   改造成微信式「输入卡片」gr.Column(类名 wx-input-card)：
   - 上：输入框（白色大圆角，占满整行）
   - 下：工具栏一行（左侧 🎙️ 麦克风 / 🖼️ 图片 / 📷 相机 + 右侧 🔇 静音 + 「发送」暖色药丸按钮）
2. 样式（暖色适老，沿用项目米色系，未改全局配色）：
   - 输入卡片浅驼色底 #F7EBD8 + 暖描边，圆角 20/16
   - 输入框白色、16px 圆角、18px 文字、暖色光标(#C88A52)，聚焦时描边框变焦糖色
   - 工具栏 icon（🎙️🎖️📷）：3 个统一改为**卡其色小方块**——浅棕底 #C19A6B、
     10px 圆角、深褐图标 #4A3218（colocación 修正 v2：此前只改在 .wx-input-bar 下，
     可能因缓存未命中；本次同时把基础规则 .media-ic button 和 .mic-btn 也改为卡其方块，
     彻底覆盖旧的圆形药丸样式，并隐藏未用的 .toolbar-icons）。
   - 「发送」= 48px 高热暖橙药丸 #D99A4E + 深褐文字（对比度 >4.5:1）
   - 「静音」= 同尺寸浅暖芯片 #F3E2C6
   - 全部按钮 ≥48px；hover 轻微上浮、active 下沉反馈
3. 组件变量名保持不变（txt/send/mute_btn/mic_btn/img_btn/cam_btn），功能绑定零改动；
   原 .input-area/.big-btn 等样式与布局删除。

【效果】
输入框简单大气、质感更好，且仍是暖米色调、按钮够大，老人看着清楚、好操作。

【风险/待实机验证】
- py_compile + import 构建通过。视觉类改动，需重启 python app.py + Ctrl+F5 硬刷新，
  实机确认：输入框外观/快捷键/发送/静音/🎙️🖼️📷 功能与布局都正常。
