修改时间：2026-10-08
修改文件：local_secrets.json（新建）
修改原因：
  用户需要为小忆陪伴助手配置 API 密钥以启用全部功能，包括：
    - DeepSeek 对话引擎
    - 火山引擎语音识别（ASR）与语音合成（TTS）
    - Bing 联网搜索
  项目启动时（app.py）会通过 _load_secret() 读取本文件。

修改内容：
  在项目根目录新建 local_secrets.json，包含以下四个密钥字段：
    1. DEEPSEEK_API_KEY     —— DeepSeek 对话/总结/复核
    2. VOLC_ACCESS_TOKEN    —— 火山引擎语音服务鉴权
    3. VOLC_APP_ID          —— 火山引擎应用 ID
    4. BING_SEARCH_KEY      —— Bing 联网搜索（app.py 第 114 行读取）

安全说明：
  - local_secrets.json 已在 .gitignore（第 51 行）中，不会被提交到 git 仓库。
  - 文件为本地使用，密钥请勿外泄。
  - 如要改用环境变量，可设置同名环境变量，优先级高于本文件。

参考文档：
  - README.md 第 134-148 行（配置 API 密钥章节）
  - app.py 第 92-124 行（_load_secret 与密钥加载逻辑）
