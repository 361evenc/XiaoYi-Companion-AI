左侧栏瘦身（反馈6 / P1）
修改文件：app.py
修改日期：2026-10-27

【修改原因】
原左栏堆了五块内容（历史对话、记忆、提醒、心情曲线、我的小传），太挤，
老人看不清、不知道点哪几个。客户要求左栏只留 4 个入口卡片，详细内容都进二级页面。

【修改内容】
1. 左栏瘦身：删掉左栏里挤在一起的历史/记忆/提醒/心情曲线/小传等所有块。
   左栏只保留入口卡片：
   - 「🧠 记忆箱」「💬 历史对话」「🔒 隐私设置」3 张导航卡，
     每张 = 图标 + 名称 + 一句话摘要（带实时数字），点开进对应二级页；
   - 「⏰ 提醒事项」卡片放最下面，点一下在左栏就地展开/收起提醒列表
     （不再进二级页）。展开后显示待办提醒清单（含任务1做好的
     「✅ 完成 / ✖ 取消」48px 大按钮）。
   卡片为 HTML，通过隐藏按钮（复用撤回按钮的 programmatic-click 机制）触发动作。

2. 二级页（占满主区，顶部有「← 返回」回到主界面）：
   - 记忆箱页：原"记忆"时间线 + 心情曲线 + 我的小传
   - 历史对话页：原搜索框 + 历史对话下拉 + 删除 + 新对话
   - 隐私设置页：隐私说明 + 「把这件事忘掉」输入框（复用"忘了吧"的
     ai_services.forget_by_request 真删逻辑）
   （提醒已改为左栏就地展开，不再单独占一个二级页）

3. 切页逻辑：主界面整体包进 gr.Row(名称 main_row)，二级页为兄弟 Column，
   _navigate_page() 用 gr.update(visible=...) 互斥切换。

4. 提醒就地展开逻辑：toggle_reminder_drawer() 翻转折叠开关 _reminder_drawer_open，
   控制左栏 reminder_drawer 的显示/隐藏，并重画提醒卡片箭头（▾/▴）。

5. 卡片摘要实时刷新：所有会改变记忆/提醒/对话数量的入口（发消息、快捷语、录音、
   新建对话、提醒完成/取消、提醒播报、隐私"忘掉"）都会联动重算 render_sidebar_cards()。

6. 新增 CSS：.xy-card 卡片、.sidebar-cards 左栏容器、.subpage 二级页、
   .subpage-back 返回按钮（≥48px 大按钮，老人好点）。

【新增/改动函数】
- render_sidebar_cards() / render_reminder_card_html()：生成左栏卡片 HTML（含实时计数）。
- toggle_reminder_drawer()：左栏提醒列表原地展开/收起。
- _navigate_page(page)：主界面与 3 个二级页互斥切换（无提醒页）。
- do_forget(phrase)：隐私页"把这件事忘掉"→ forget_by_request 真删 + 刷卡片/记忆。
- 一并改动：handle_reminder_action、refresh_panels、poll_reminder_events、enter_chat
  增加对 sidebar_cards 的联动刷新。

【风险/待实机验证】
- 切页为 Gradio 纯前端 visible 切换（视觉类改动），本地无浏览器环境无法自动验证，
  需重启 python app.py 后浏览器 Ctrl+F5 硬刷新，实机点测：
  ① 四张卡片是否好看、点了是否都进到对应二级页；② 各页「← 返回」是否回到主界面；
  ③ 提醒页「完成/取消」是否能用且数字联动；④ 隐私页"忘掉"是否生效。
