# XiaoYi-Companion-AI# 
🌸 小忆陪伴助手

> 一个专为老年人打造的 AI 智能陪伴系统，融合语音交互、对话记忆、情感支持与主动关怀功能。

---

## 📖 项目简介

**小忆陪伴助手** 是一款面向老年用户的 AI 语音陪伴应用。老人可以通过打字或语音与 AI "小忆" 进行对话，小忆会记住用户说过的重要信息（健康状况、用药情况、家庭琐事、生活习惯、情绪变化等），并在适当时机主动发起关怀提醒——就像一位贴心的晚辈常伴左右。

项目基于 **Gradio** 构建 Web 界面，使用 **DeepSeek** 大模型驱动对话，接入 **火山引擎** 语音识别（ASR）与语音合成（TTS）服务，实现完整的语音交互闭环。

## ✨ 功能特性

### 🗣️ 语音对话
- **一键录音**：点一下 🎙️ 开始说话，再点一下自动发送（无需二次点击停止）
- **语音播报**：小忆的回答自动转为语音播放（可静音）；文字先显示、语音随后合成，不互相等待
- **语音链路优化**：抗混叠重采样、音量增益归一化（老人说话小声也能识别）、尾音补静音防截字、长文本分段合成
- **文字输入**：也支持打字输入，适合不习惯语音的用户
- **快捷按钮**：一键发送常用语——"我今天挺好的"、"有点想你了"、"身体有点不舒服"、"讲讲以前的事"

### 🌐 联网搜索
问"今天天气怎么样"、"最近有什么新闻"等时效性问题时，小忆自动搜索网络（Bing），并结合搜索结果用口语转述给老人（DeepSeek 总结），本地模型不联网时照常聊天。

### 🧠 智能记忆
小忆会自动从对话中提取关键信息并记住，包括：

| 类别 | 识别内容举例 |
|------|-------------|
| 🏥 **健康** | 头疼、头晕、膝盖疼、腰疼、不舒服 |
| 💊 **用药** | 降压药、吃药、阿司匹林、中药 |
| 🔑 **物品** | 老花镜、钥匙、遥控器、手机、血压计 |
| 👨‍👩‍👧‍👦 **家人** | 儿子、闺女、孙子、孙女、老伴 |
| 🌱 **习惯** | 浇花、买菜、散步、打太极 |
| ❤️ **情绪** | 难过、孤单、想家了、高兴 |

所有事件以时间线形式展示在侧边栏 **「重要事件」** 面板中，一目了然。

### 🔔 主动关怀
- **用药提醒**：当老人提过吃药后，小忆会主动询问"该吃药啦，我帮您记着呢"
- **健康回访**：老人提到身体不适后，小忆过一会儿会主动关心"现在好点了吗？"

### ⏰ 智能提醒（"五分钟后提醒我"→到点反馈）
一句话设提醒，到点真的响，还能确认是否办妥：

- **设提醒**："五分钟后提醒我喝水"、"过半小时叫我吃药"、"明天早上八点复查"、"每天晚上九点泡脚"、"每周三下午四点量血压"
- **模糊时间**："睡醒后提醒我吃药" → 小忆只澄清一次（附建议时长），绝不追问第二次
- **到点反馈**：聊天窗自动弹出人设话术 + 三声柔和的中低频提示音（静音状态下也保留提示音）
- **确认闭环**：到点后追问"喝了吗"，老人答"喝完了"记为完成；答"等会儿"顺延10分钟；无应答每2分钟补提醒（共2次），仍未确认升级记录"请家人留意"
- **反操作**："把提醒取消了"、"把提醒改到下午三点"、"我有什么提醒"（语音列出待办）
- **可靠性**：任务落盘 `reminders.json`，重启不丢；断电期间错过的提醒启动时补交
- **量化指标**：侧边栏"提醒事项"面板实时展示近30天提醒完成率/用药依从率

详见《[提醒功能说明.md](提醒功能说明.md)》。

### 🎭 三种性格可选

| 性格 | 风格描述 |

| 🧘 **踏实务实** | 稳重真诚，朴实贴心，像一位靠谱的晚辈 |

| 💕 **暖心知心** | 温柔细腻，共情力强，像贴心家人 |

- 搜索过往对话关键词

- 删除不需要的对话记录

### 🌐 Web 界面

- 暖色调大字体界面，适合老年人操作

## 🛠️ 技术栈

| 组件 | 技术 |
|------|------|
| Web 框架 | [Gradio](https://www.gradio.app/) |
| 对话引擎 | 本地小忆 3B 模型（Qwen2.5 微调，无需训练，直接推理；GPU/CPU 自适应） |
| 联网搜索 | Bing 免费抓取 + DeepSeek 总结（密钥放 `local_secrets.json`） |
| 语音识别（ASR） | 火山引擎语音识别 |
| 语音合成（TTS） | 火山引擎语音合成（音色可配 `VOICE_TYPE`） |
| 提醒系统 | 自研 `reminder.py`（中文时间解析/调度/确认闭环，纯标准库） |
| 运行环境 | Python 3.10+ |

## 📦 安装指南

### 前置条件

- Python 3.9 或更高版本
- DeepSeek API 密钥（[官网申请](https://platform.deepseek.com/)）
- 火山引擎语音服务 Access Token 和 App ID（[火山引擎控制台](https://console.volcengine.com/)）

### 安装步骤

```bash
# 1. 克隆或下载项目
cd 小忆陪伴助手

# 2. （推荐）创建虚拟环境
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt
```

### 配置 API 密钥

在项目根目录创建 `local_secrets.json`（已加入 .gitignore，不会提交到仓库）：

```json
{
  "DEEPSEEK_API_KEY": "sk-你的DeepSeek密钥",
  "VOLC_ACCESS_TOKEN": "你的火山引擎AccessToken",
  "VOLC_APP_ID": "你的火山引擎AppID"
}
```

也可以用环境变量 `DEEPSEEK_API_KEY` / `VOLC_ACCESS_TOKEN` / `VOLC_APP_ID` 配置，优先级高于本地文件。

> **注意**：不配置语音服务不影响文字聊天功能，只是语音输入和语音播报不可用。若只测试文字对话，可以跳过语音配置。

## 🚀 运行项目

```bash
python app.py
```

启动后，终端会显示访问地址，默认在 `http://localhost:7861` 打开浏览器即可进入。

### 使用流程

1. **设置页面**：输入老人姓氏（如"张"）、选择称呼（奶奶/爷爷）、选择小忆的性格
2. **点击「进入聊天」**：进入主聊天界面
3. **开始对话**：
   - 在底部文本框输入文字后点击「发送」
   - 或点击「🎙️语音」按钮，对着麦克风说话
   - 或点击快捷按钮快速发送常用语
4. **查看记忆**：右侧（或下方）的「重要事件」面板展示小忆记住的信息
5. **管理对话**：左侧「历史对话」下拉框可搜索、加载、删除历史记录
6. **静音控制**：点击「🔇 静音」可关闭语音播报

## ⚙️ 自定义配置

`app.py` 中的 `custom_css` 变量包含了全部界面样式，可自由调整颜色、字体大小、圆角等。

`app.py` 中 `PROMPT_PRACTICAL`、`PROMPT_HUMOR`、`PROMPT_CARING` 三组变量分别对应三种性格的系统提示词，可按需修改。

`extract_memory()` 函数中的健康、用药、物品等关键词字典可根据实际需求增删。

## ❓ 常见问题

**Q: 语音识别不工作？**
A: 请检查火山引擎的 AccessToken 和 AppID 是否已正确填写，且账户内有可用额度。

**Q: 语音播报没有声音？**
A: 检查是否处于静音状态（按钮显示「🔇 静音」表示已静音），点击切换为「🔊 取消静音」。

**Q: 对话记录丢失？**
A: 每次启动时程序会自动备份 `conversations.json` 和 `memory_events.json` 到 `backups/` 目录（保留最近 5 份），可从备份恢复。

**Q: 提醒到点没响？**
A: 提醒需要网页保持打开（轮询每15秒一次）；重启程序后断电期间错过的提醒会自动补交。设提醒说"十秒后提醒我XX"可快速自测。

**Q: DeepSeek 调用失败？**
A: 检查 API Key 是否正确、账户余额是否充足、网络是否能访问 `api.deepseek.com`。
