修改时间：2026-10-08
修改文件：app.py
修改原因：
  任务5：语音交互升级。
  1) 原来全站只有一种音色（BV705 炀炀），三种人格听感无差异；
  2) TTS 语速固定 0.8，不随情绪/场景变化（开心应轻快、关心应放慢、提醒应清晰有力）；
  3) 语音播放器被 CSS 完全隐藏（audio-hidden），老人无法暂停/继续，也看不到播放进度。

修改内容（均在 app.py）：

【1. 人格 → 音色映射（L126-L133）】
   新增常量 PERSONA_VOICE：
     踏实务实 → BV002_streaming（通用男声，沉稳）
     风趣幽默 → BV004_streaming（开朗青年，活泼男声）
     暖心知心 → BV104_streaming（温柔淑女，柔和女声）
   音色 ID 取自火山引擎官方音色列表；如需更换可到火山控制台试听后
   直接改这三个值。若某音色返回鉴权错误（未开通该音色授权），
   可退回 BV002/BV705 等基础音色。

【2. 场景 → 节奏映射（L135-L142）】
   新增常量 EMOTION_SPEED：愉悦→0.95（快一点）、平淡→0.8、低落→0.7（慢一点）
   新增常量 REMINDER_TTS_PARAMS：speed 0.85 / pitch 1.05 / volume 1.5（提醒清晰有力）
   新增常量 CARING_TTS_PARAMS：speed 0.7（主动关怀放慢放柔）

【3. TTS 底层参数化（L558-L575、L593-L605）】
   tts_request(text, voice_type=None, speed=0.8, pitch=1.0, volume=1.3)
   text_to_speech(text, voice_type=None, speed=0.8, pitch=1.0, volume=1.3)
   —— 原固定值（0.8/1.3/1.0）变为默认参数，旧调用点行为不变（向后兼容）

【4. 情绪落点（L311、L882-L883）】
   UI_STATE 增加 "last_emotion"（默认"平淡"）；
   chat_response 中每轮情绪分析后写入 UI_STATE["last_emotion"]。

【5. 播报函数接入（L1060-L1074）】
   play_reply_audio：按 UI_STATE["personality"] 选音色、
   按 UI_STATE["last_emotion"] 选语速 → text_to_speech(content, voice, speed)
   play_mic_reply_audio 委托 play_reply_audio，自动继承（未改）

【6. 主动关怀放慢（L1130-L1142）】
   inject_proactive_message 的 TTS 改为
   text_to_speech(msg, voice=人格音色, **CARING_TTS_PARAMS)  # speed 0.7

【7. 提醒清晰有力（L1528-L1536）】
   build_reminder_audio 的 TTS 改为
   text_to_speech(text, voice=人格音色, **REMINDER_TTS_PARAMS)  # 0.85/1.05/1.5

【8. 播放进度条 + 暂停/继续（CSS L1679-L1686、组件 L1857-L1860）】
   - custom_css 新增 .audio-bar 小型语音条样式（暖色圆角卡片、40px 高、
     隐藏下载按钮）；原 .audio-hidden 样式保留备用
   - audio_output 组件从 Blocks 顶层（渲染在欢迎页上方）移到
     main_view 聊天窗（chat）正下方，elem_classes 改 "audio-bar"，
     autoplay=True 保留，buttons=[] 隐藏下载/分享按钮
   - Gradio Audio 原生自带：播放/暂停切换按钮 + 可拖动进度条 + 时长显示，
     自动播放后老人可随时点暂停/继续、拖进度条重听

    - 三人格同文本实测：BV002 时长3.71s / BV004 3.73s / BV104 3.98s，
      md5 全不同 → API 层音色确实在变

  效果：所有语音输出只播放声音，界面不显示任何播放器组件
  py_compile 通过
