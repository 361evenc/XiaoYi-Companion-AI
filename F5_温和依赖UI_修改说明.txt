F-5 温和依赖 UI 套件 —— 修改说明
========================================
日期：2026-11-08
范围：仅前端（后端 B-7 素材库 / B-8 盲盒·收集瓶接口未落地，按约定先做“前端 UI + 本地契约”）

一、修改原因
----------------------------------------
F-5 要求盲盒/收集瓶/前奏音/反向索求有完整体验，且防沉迷护栏必须落在代码里、可验证：
零“再来一次”按钮、零连续天数徽章、零缺席提醒、统计只显“一共攒了 N 个”、
前奏音 1:1 只对应正反馈事件、语音“再放一个”到上限只用固定话术。
由于 B-7/B-8 尚不存在，本卡先用本地契约（localStorage）实现全部护栏与 UI，
接入后端时只替换数据来源，护栏逻辑不动。

二、新增文件
----------------------------------------
1. frontend/src/data/t6Params.js
   - T-6 参数表（代码即参数，话术审核以此为准）：
     盲盒 1 次/天、语音额外“再放一个” 2 次/天；
     前奏音只允许 weather_answered / find_object_ok / family_voice 三类事件，
     每事件 1 次、只在播报前响；
     到上限固定话术：“今天就到这儿吧，明天还有——我给您讲讲之前那件有意思的事好不好？”；
     禁用句式：“不行，今天次数用完了”“您怎么这么倔呀”；
     UI 禁用字样清单（再来一次/连续天数/断签/本周/缺席等）。
2. frontend/src/data/warmMoments.js
   - B-7/B-8 未落地前的演示素材（盲盒 5 条、收集瓶 3 条），
     全部在界面上打「演示素材」标签，不冒充老人的真实回忆。
3. frontend/src/services/warmDependency.js
   - 本地契约：
     · peekBox 只读不消耗；openBox 一天硬上限 1 个；同一天重复打开返回同一条内容（不是抽卡）；
     · 收集瓶对外只返回 { total }，不派生周统计/连续天数/缺席数据；
     · requestExtraPlay：有额度放、到上限只回固定话术；
     · handleVoiceRequest：整句“再放一个/再放一遍/再来一个/再开一个”才拦截，
       带内容的“再放一个戏曲”照常交给对话模型；
     · announcePositive：非三类正反馈事件一律拒绝（无好事不响），
       正反馈事件严格“前奏音 1 次 → 播报 1 次”；
     · beginPositive：天气、孩子语音这类每天一次的“好事”，同一天只响一次；
     · 状态按自然日重置当日额度，收集瓶不清空。
4. frontend/src/views/BlindBox.vue（/blindbox）
   - 开启动画 1.3 秒 + 34px 大字记忆 + 照片 + “念给我听”；
   - 全程只有一个“打开今天的盲盒”，打开后不再出现任何开启入口；
   - 当天已开时只陈述“今天这个盲盒已经开过了，明天还有一个小惊喜。”。
5. frontend/src/views/Bottle.vue（/bottle）
   - 统计只有“一共攒了 N 个美好瞬间”；无周统计、无连续天数、无缺席提醒；
   - 美好瞬间列表：照片 + 文字 + 语音回放；
   - 子女语音/夸赞作为正反馈事件：前奏音 1 次 → 播报 1 次，一天一次。
6. frontend/src/components/ReverseAskCard.vue
   - 反向索求任务卡：大字“告诉我今天天气怎么样？”；
   - “小忆先问一句”是请求、不是好事，所以不放前奏音。
7. frontend/tests/f5_guardrails.mjs
   - 5 条固定护栏测试（node tests/f5_guardrails.mjs），供第二人复核直接跑。

三、修改文件
----------------------------------------
1. frontend/src/views/Chat.vue
   - 挂载 ReverseAskCard；
   - 老人说出天气类内容 → 当天首次：前奏音 1 次 → 再播报小忆回复（避免两路声音叠加）；
   - 找物命中（正反馈事件）→ 前奏音 1 次，随后展示找物卡；
   - 文字/语音输入命中“再放一个”整句 → 本地契约接管，不进对话模型：
     有额度回“好，再给您放一个：<某条美好瞬间>”，到上限回 T-6 固定话术。
2. frontend/src/router/index.js：新增 /blindbox、/bottle。
3. frontend/src/components/SidebarCards.vue：左侧新增“今天的盲盒”“收集瓶”两个入口。
