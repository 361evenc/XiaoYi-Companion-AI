【修改原因】
前端重构（Vue3 + Vite + FastAPI）已全部完成，旧版 Gradio 界面不再使用，
按用户要求删除旧代码。app.py 是新后端的「引擎库」（backend.core.state
即 import app 复用其中全部函数），因此不能删整个文件，只删纯界面段。

1. app.py
   - 删除 2502–2798 行「Gradio 界面」段：
     · 界面搭建（gr.Blocks：欢迎页/主界面/记忆箱/历史/隐私四个二级页）

       show_emotion_chart / refresh_panels 等）与全部事件绑定
     · gr.Timer 定时器（主动关怀/音频清理/历史修剪/提醒轮询）
     · if __name__ == "__main__" 的 demo.launch 入口
   - 原位置换成说明注释。删除前已备份：backups/app.py.20261028_删UI段前.bak
   - python app.py 现在不再起界面（模块仅作引擎库被 backend 引用）。

2. 定时任务归属（删段后无遗漏）
   - 提醒调度轮询：app.py 模块级 daemon 线程，import 即启动，不受影响

   - 主动关怀注入：前端轮询 POST /api/proactive（Phase 7A 已上线）
   - 提醒到点推送：WebSocket /ws（Phase 7A 已上线）

3. 启动小忆.bat

     已失效。改为新版启动方式：
     后端：python -m uvicorn backend.main:app --port 8010
     前端：cd frontend && npm run dev（Vite，5174）
     并自动打开 http://localhost:5174
