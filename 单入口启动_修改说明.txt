单入口启动器（run.py）· 修改说明
============================================================

【修改原因】
用户要求：启动后端时前端自动跟着启动，一条命令跑起整个应用，
不再需要手动开两个终端分别起 uvicorn 和 vite。

【修改内容】

1. run.py（新建，项目根）
   - 单入口启动器：python run.py 一条命令
   - 启动顺序：先以子进程拉起前端 Vite（npm run dev，端口 5173 被占
     时 Vite 自动换 5174），再启动后端 uvicorn（FastAPI，8010，单 worker）
   - 退出联动：Ctrl+C 或关闭窗口时，用 taskkill /F /T 杀掉前端进程树
     （npm → node → vite），atexit + SIGBREAK 双保险，保证前后端一起停
   - 已在跑检测：启动前探测 5173/5174/5175 端口（IPv4），前端已运行则跳过
   - 后端 8010 被占时 uvicorn 退出 → finally 同样清理前端

2. 启动小忆.bat（改写）
   - 原版开两个窗口分别跑服务，现改为单窗口运行 python run.py
   - 保留延时自动打开 http://localhost:5174/（端口以 Vite 窗口打印为准）

【验证】
- 完整启动：run.py 先后拉起 Vite（ready 279ms）与 uvicorn(8010)，
  /api/health 200，前端 HTTP 200
- 退出清理：后端因端口冲突退出时日志打印"[run] 前端已停止"，
  其子进程 vite 一并消失（真实日志验证）
- 说明：本机 5173 被一个仅绑 IPv6 ::1 的无关进程占用（PID 26660，
  非本项目），因此 Vite 会自动使用 5174 —— 属正常现象，访问
  http://localhost:5174/ 即可

【使用方式】
  方式一：双击 启动小忆.bat
  方式二：终端执行 python run.py（在项目根目录）
  停止：Ctrl+C 或直接关闭窗口（前后端一起停）
