F-4 时间线页 —— 修改说明
======================================

修改时间：2026-11-08
任务卡：F-4 时间线页（负责人：前端；前置：B-5 四维检索 API）

一、修改原因
------------------------
现在只有"重要事件时间线 + 照片记忆墙"（按时间一维），家庭记忆守护者这条差异化主线
只有后端数据、没有老人看得见的出口。本卡把时间线扩成四维（人 / 物件 / 时间 / 地方），
让老人能翻"孙子那年我们干啥了"（按人）、"厨房那阵子发生了啥"（按地方），
并用大字 + 翻页的适老交互（不滚长列表）。

二、修改内容（新增 1 个文件，改动 6 个文件）
------------------------
1. 新增 frontend/src/views/Timeline.vue（家庭时间线页 /timeline）
   - 四个大按钮切换维度：👤 人 / 📦 物件 / 🗓️ 时间 / 🏠 地方（min-height 72px）；
   - 人/物件/地方：常见说法 chip + 大字输入框 + "翻一翻"；
   - 时间：年份 chip（今年起往前 5 年，min-height 64px），老人不用打字；
   - 结果每页 10 条，"◀ 上一页 / 下一页 ▶" 按钮 min-height 64px，
     显示"第 X / Y 页""一共 N 件"，不做长列表滚动；
   - 每条显示图标（📌事实 / 💬情节 / 💭反思）、大字标题、老人原话「…」、年月日；
   - 人物维度只按 B-5 的 resolved.kind 说话：
     profile → "这是您说过的「XX」"；fallback_visitor → "这个人我还没有记下名字，
     先给您看看「有客人来过」的事"，**不显示猜的人名**；visitor/pet/self 分别有对应说法；
   - 空结果、接口失败都有老人能懂的提示，不抛技术错误。

2. 修改 memory_system.py（B-5 search 补第四维 time，最小增量）
   - by 允许 person|object|scene|time；
   - 新增 _resolve_time(q, now)：支持 "2024"、"2024年5月"、"2024-05"、"今年"、"去年"、
     "上个月"，返回 {kind:"time", label, start, end}（左闭右开），认不出返回 None；
   - time 分支：按发生时间倒序排列（翻时间线就是按时间看，不走三因子打分）；
   - 仍沿用原检索池（retrievability ≥ FORGET_THRESHOLD）——"已经被忘掉的"不显示，
     与遗忘曲线/记忆箱口径一致；检索依旧只读，不强化记忆；
   - 原 scene 分支从 else 改成 elif by == "scene"（加 time 维度必须的等价改动）。

3. 修改 backend/services/memory_service.py、backend/api/memory.py：仅同步 docstring（四维契约）。

4. 修改 frontend/src/api/index.js：新增 memorySearch({ q, by })，默认 k=50（B-5 上限）。

5. 修改 frontend/src/router/index.js：新增 /timeline 路由。

6. 修改 frontend/src/components/SidebarCards.vue：左栏新增"🗂️ 家庭时间线 / 按人、按地方翻旧事"。

7. 修改 frontend/src/views/Memory.vue：新增"翻旧事"入口卡 → 家庭时间线
   （把一维重要事件接到四维页面）。

三、人物档案口径（按任务卡写死，本卡遵守，不新增入口）
------------------------
- 建档唯一路径 = 老人自己主动说"这是我XX" + 小忆确认；
- AI 不猜（猜错人物 = 叫错名的信任爆点），子女端不建档（零子女配置原则）；
- 档案字段 = 姓名 + 称谓（不存人脸特征）；说"别叫了"可删，删后退回三类；
- 冷启动无档案 → 退回三类（只显"有客人来过"），这是不猜的代价，接受。
- 本卡只做**展示**：时间线页没有任何"新建档案"入口，也不给查无档案的人显示名字。
  聊天里"这是我孙子"→ 确认 → 建档的链路属聊天/后端接线（memory_system 已有
  add_person_profile，但当前没有生产调用点），不在本前端卡范围，见"待办"。

五、未完成 / 需后续卡或人工
------------------------
1. 验收要求"四维各测 ≥30 条，用 H-6 实测 3 户真实数据（经同意）"——
   本机记忆库只有 7 条，无法做真实数据验收；已用造数据验证时间维度与分页口径，
   真实数据验收需在 H-6 环境执行。
2. 翻页交互"老人独立会用"需 H-6 实测复核（本机数据不足一页，翻页按钮为禁用态）。
3. 聊天里"这是我孙子"→ 小忆确认 → add_person_profile 的建档流尚未接线
   （B-5 已有 add_person_profile 与检索优先逻辑，缺调用点）；没有这条流，
   人物维度会一直走 fallback_visitor（UI 已按"不猜"处理）。
4. 时间维度依赖遗忘曲线：掉到 FORGET_THRESHOLD 以下的旧事不会出现在时间线，
   这是与小忆"会忘记"一致的口径，不是 bug；若产品要"归档可查"，需另开卡。

六、如何复核
------------------------
1. python run.py（前端 5173 / 后端 8010），左栏点"家庭时间线"；
2. 切四个维度各查 30+ 条（H-6 数据）：核对条数、排序、日期、人物兜底话术；
3. 老人角色扮演：只点大按钮和"上一页/下一页"完成翻页，不看滚动条。
